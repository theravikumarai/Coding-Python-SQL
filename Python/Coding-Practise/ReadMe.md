# But There's One Important Thing

    Since your original goal is:

    Service-based companies first → Product-based companies later

    I would split your preparation into two levels.

    Level 1 — Service-Based

    You've completed:

    Linear Traversal
    Hashing
    Two Pointers
    Sliding Window
    Binary Search
    Sorting

    Next:

    Stack
    Queue
    Linked List
    Recursion
    Basic Trees

    That is enough to make your foundation quite strong.

Level 2 — Product-Based

Later, when you decide to seriously target product companies:

Advanced Trees
Heap
Graphs
Backtracking
Dynamic Programming
Greedy
Advanced Binary Search
Advanced Sliding Window
Advanced Two Pointers
Trie
Union-Find
Segment Tree
Fenwick Tree

You do not need all of that right now.
